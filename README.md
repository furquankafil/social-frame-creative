# Social Frame Creative — Website

Premium static agency website for **Social Frame Creative** (New Delhi, India).

- **Stack:** HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript + Custom CSS. No build step.
- **Run locally:** `python -m http.server 8000` in this folder, then open `http://localhost:8000`.
- **Deploy:** upload these files to any static host (currently Netlify from `main`).
- **Contact form:** delivers via EmailJS — see `EMAIL_SETUP.md`. Destination: `socialframecreative@gmail.com`.
